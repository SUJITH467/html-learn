# My Portfolio

A simple static portfolio website for Sujith J. The site introduces the author, lists skills and projects, and provides contact information.

## Pages

- `index.html` - Home page and portfolio overview
- `about.html` - About page
- `skills.html` - Skills page
- `project.html` - Projects page
- `contact.html` - Contact page

## Run Locally

No build tools or dependencies are required. Open `index.html` in a web browser.

For a local development server, run:

```powershell
python -m http.server
```

Then visit `http://localhost:8000`.
